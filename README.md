# Sanjana Dwivedi — AI Engineer Portfolio

A modern, interactive 3D and responsive portfolio website showcasing AI engineering projects, skills, and experience.

## ✨ Features
- **Dynamic 3D Portal Canvas**: Interactive particle and portal background animations.
- **Projects Showcase**: Interactive project cards and modal views with tech stack breakdowns and live demo links.
- **Experience & Education Timeline**: Detailed professional milestones in AI, LLMs, and GenAI development.
- **Skills Matrix**: Categorized technical proficiencies across GenAI, LLMs, Backend, Vector DBs, and Tools.
- **Modern Responsive UI**: Built with React 19, Vite, Tailwind CSS, and Framer Motion.

## 🛠️ Tech Stack
- **Framework:** React 19, Vite
- **Styling:** Tailwind CSS, Framer Motion, AOS
- **Deployment:** GitHub Pages / Vercel / Netlify

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
